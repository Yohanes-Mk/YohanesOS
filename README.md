# YohannesOS

The source repository for [Yohannes Nigusse's portfolio](https://yohanes-os.vercel.app/): an interactive archive of applied AI systems, backend work, research, and selected product projects.

## Highlights

- Current professional profile, project case studies, and downloadable resume.
- Content maintained in a typed portfolio data model so the site and resume stay aligned.
- Built with React, TypeScript, Vite, and modern CSS.

## Development

```bash
cd project
npm install
npm run dev
```

Use `npm run build` to create a production build and `npm run build:resume` to regenerate the public resume PDF.
